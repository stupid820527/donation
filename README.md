# 聖義堂班長的記帳 App

出遊記帳、保險名單、普渡登記。純靜態網頁，開網址就能用，資料存在瀏覽器裡。

## 上線步驟（GitHub Pages）

1. 把 `index.html` 與 `.nojekyll` 上傳到這個 repo 的根目錄（GitHub 網頁上 **Add file → Upload files** 即可）。
2. 進 **Settings → Pages**，Source 選 **Deploy from a branch**，branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://stupid820527.github.io/-/`。手機、電腦開同一個網址都能用。

## 功能

- **本次活動** — 地點、日期；費用項目（油香、花籃水果、金紙、紅包、午餐、車資、保險）名稱與金額都可改、可增可刪；贊助名單姓名＋隨喜金額；即時計算收款總額、支出總額、剩餘餘額；勾選誰要去。
- **普渡** — 名子、桌數、普渡米包數，含合計與列印檔。
- **名冊** — 姓名、出生年月日、身分證字號，手動新增，存一次每場勾選。
- **歷次** — 每場出遊各自獨立，可切換；含備份檔匯出／匯入。
- **列印** — 捐款表、保險名單、普渡名單皆可列印或存成 PDF（手機瀏覽器選「列印 → 儲存為 PDF」）。

## 資料存在哪裡

存在該裝置瀏覽器的 localStorage。關掉網頁不會消失，但**換裝置不會自動同步** — 用「歷次」分頁的匯出／匯入備份檔搬移。

要真正跨裝置即時同步，需要接資料庫（Supabase 免費方案可行）：建一張 `ledgers` 表（`code text primary key`、`data jsonb`、`updated_at timestamptz`），前端改成讀寫 REST API。名冊含身分證字號屬個資，接雲端前務必加上登入驗證與 RLS 權限，不可用公開共享碼。

## 注意

- Pages 網址是公開的（本頁已加 `noindex` 避免被搜尋引擎收錄，但知道網址的人仍可開啟）。名冊含身分證字號，請勿把網址給不相干的人。
- 想加密碼鎖或雲端同步，再提出即可。
